# 포켓카드 레이더

포켓몬 카드 시세 · 이벤트 알림 · 신규 카드 알림 · 카드샵 찾기 웹앱 (Node.js만 있으면 실행, 추가 설치 없음)

## 웹 버전 (GitHub Pages)
GitHub Actions가 **2시간마다** 시세·뉴스·신규 세트를 모아 `site/`를 만들고 GitHub Pages에 배포합니다.
데이터 출처 사이트에 부담을 주지 않도록 요청 사이에 1.5초씩 쉬고, 한 번에 8개 세트씩만 갱신해서 하루에 전체 98개 세트가 한 바퀴 돕니다.
바로 갱신하려면 저장소의 **Actions → 시세 수집 & 배포 → Run workflow**를 누르세요.
- 웹 버전은 수집해 둔 카드(98개 세트의 힛카드) 안에서 검색합니다.
- 카드샵 지도·환율·해외 상세 시세(TCGdex)는 브라우저에서 바로 불러옵니다.

## 로컬 실행 (실시간 검색)
```
node server.js
```
브라우저에서 http://localhost:5178 접속 (주소창의 설치 아이콘으로 앱처럼 설치 가능)

## 기능
| 탭 | 내용 | 데이터 출처 |
|---|---|---|
| 💰 시세 | 🇰🇷 한글판 / 🇯🇵 일본판 / 🇺🇸 북미판 시세를 탭으로 비교. 시세 = 최근 30일(부족하면 90일) 같은 상태 거래의 중앙값, 최저·최고가(이상치 제외), 한 달 전 대비 등락 | 포케폴리오(MVC 네이버카페 등 실거래 집계, 일본 snkrdunk, 북미 eBay), 포카존 거래글 |
| 🔥 세트별 힛카드 | 98개 세트(MEGA·스칼렛&바이올렛·소드&실드·썬&문·XY·BW·클래식·마스터볼 미러), 등급(SAR·SR·AR… / 30주년은 FUR·RGB·복각)·상태(Raw·PSA) 필터, 시세 없는 카드는 접어서 표시 | 위와 동일 |
| ⭐ 관심 카드 | 가격이 설정한 % 이상 변하면 알림 | 위와 동일 |
| 🎉 이벤트 | 이벤트·대회·프로모·팝업 소식, 새 소식 알림 | Google 뉴스 |
| ✨ 신규카드 | 한국 정식 발매 세트(발매일·가격·D-day) + 해외 최신 확장팩, 새 세트 알림 | 포켓몬 카드 게임 공식 사이트, TCGdex |
| 🗺️ 카드샵 | 내 위치/지역 주변 카드샵 지도 + 네이버·카카오·구글 지도 바로가기 | OpenStreetMap |

KREAM·콜렉토리·카드냥·포카트레이드·네이버 카페는 자동 수집이 불가(로그인 필요/수집 금지/브라우저 전용)해 바로가기 링크로 제공합니다.

## 참고
- 알림은 앱 탭이 열려 있는 동안 동작합니다(🔔에서 주기·기준 설정).
- 시세는 공개된 거래 기록 기준 참고용입니다. 거래가 적은 카드는 실제 매물가와 차이가 날 수 있습니다.
